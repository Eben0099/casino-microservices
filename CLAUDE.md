# Project conventions

## Git commits

**Never add any Claude Code attribution to commits or pull requests.**

- No `Co-Authored-By: Claude` trailer
- No "Generated with Claude Code" footer
- No mention of Claude, AI, assistant, or similar in the commit message or PR body

Commits must look like they were authored solely by the developer. The git user (`Eben0099`) is the only attribution.

This rule applies to every commit, amend, and PR description — without exception, without needing to be reminded.
